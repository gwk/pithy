# ASCII grammar

[ascii.legs](ascii.legs) recognizes newline, runs of spaces, and runs of ASCII characters in each represented Unicode general category.
Its single mode is `main`. Non-ASCII input produces `invalid` tokens.

Token kinds are lowercase class names, such as `ascii_uppercase_letter` and `ascii_decimal_number`.
The grammar is generated by `tools/gen-charset-grammar.py` and is used for examples, property tests and runtime benchmarks.
Run `make gen-grammars` from the repository root to regenerate it.
