# Unicode grammar

[unicode.legs](unicode.legs) recognizes newline, runs of spaces, and runs of characters in Unicode general categories.
Its single mode is `main`. Token kinds are lowercase category names, such as `uppercase_letter` and `decimal_number`.
Surrogates are excluded because they cannot be encoded as valid UTF-8.

The grammar is generated by `tools/gen-charset-grammar.py` and is used for property tests and compilation and runtime benchmarks.
Run `make gen-grammars` from the repository root to regenerate it.
See [Named Character Classes](../character-classes.md) for category definitions and aliases.
